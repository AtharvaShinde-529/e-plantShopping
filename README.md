# e-plantShopping

## Paradise Nursery Shopping Application

Welcome to the **e-plantShopping** repository! This project is a React-based shopping cart application for an online plant shop called Paradise Nursery.

### Application Overview
The Paradise Nursery shopping application allows users to browse a variety of house plants, add them to a shopping cart, and manage their selections. 

### Key Features
- **Landing Page:** A welcoming landing page with a "Get Started" button to enter the shop.
- **Product Listing:** A dedicated page displaying different categories of plants (e.g., Aromatic, Medicinal) with cards showing images, names, descriptions, and costs.
- **Shopping Cart:** A dynamic cart page that displays selected items, allows users to increase/decrease quantities, delete items, and view the total cart amount.
- **Navigation:** A responsive navigation bar showing links to the landing page, plants page, and a cart icon that dynamically updates with the total number of items in the cart.

### Technologies Used
- React (Functional Components & Hooks)
- Redux Toolkit (State Management)
- React Router (Navigation)
- CSS for styling
